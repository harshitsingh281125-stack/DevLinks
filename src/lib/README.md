# Lib

Reusable utilities, clients, constants, and helpers.

- `types.ts` — domain types (`Bookmark`, `Collection`, …)
- `supabase.ts`, `env.ts` — client and env loading
- `theme.ts` — light/dark preference store
- `format.ts` — `Intl`-based date and count formatting
- `resourceTypes.ts` — display labels for resource types
- `roadmap.ts` — `sortByPosition`, `moveItem`
- `export.ts`, `seo.ts`, `analytics.ts`, `site.ts` — export serializers, head tags, events, author constants
- `useFocusTrap.ts`, `useDismiss.ts`, `useDocumentHead.ts` — small hooks
